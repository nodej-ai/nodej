# NodeJ for Claude

Plugins and prompts from NodeJ. Browse them, with examples, at [nodej.ai/foundry](https://nodej.ai/foundry).

## Add the marketplace

In Claude Code:

```
/plugin marketplace add nodej-ai/nodej
```

Then install a plugin:

```
/plugin install signal-brief@nodej
```

## Plugins

| Plugin | What it does | Run it |
|---|---|---|
| [signal-brief](https://github.com/nodej-ai/signal-brief) | Turn one news signal into a three-page executive brief. | `/signal-brief:brief <your signal>` |

Don't use Claude Code? Each plugin's page on [nodej.ai/foundry](https://nodej.ai/foundry) has a copy-and-paste version.
